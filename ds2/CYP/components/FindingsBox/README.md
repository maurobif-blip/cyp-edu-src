# FindingsBox

A tinted box for text that comes from a source outside the report narrative: an evaluation, a field visit, a meeting. The consumer provides a title that names the source, and the text.

- Ground `surface-soft`, square corners, no border, 32px padding.
- Title in `heading-3`, capitals. Text in `cyp-prose`, two columns.
- One box per page at most. Do not nest charts or tables in it.
