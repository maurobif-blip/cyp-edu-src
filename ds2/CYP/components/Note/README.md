# Note

Several lines of text inside a card: a remark from a person, an instruction that needs more than one sentence. The consumer provides an optional title line and the text.

- `cyp-note` on `surface-soft`, text in `small`, the title in `small-strong`. Square corners, no border.
- Tones: `cyp-note--ok`, `cyp-note--warn`, `cyp-note--danger` take the soft fill and the text colour of the status. The title says what the tone means.
- A note belongs to the card it sits in. `SyncBanner` stays for one sentence about the whole screen.
- No button inside a note.
