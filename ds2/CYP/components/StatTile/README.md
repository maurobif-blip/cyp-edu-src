# StatTile

One number with its name, for the home page of an app and the top of an internal template. The consumer provides the name, the number, and one short line that gives its base or target.

- Name in `label-caps`, `ink-muted`. Number in `figure`, `blue`. Note in 13px.
- Three tiles in a row on a computer and on A4, one per row on a phone.
- A tile shows one number. No chart, no icon, no trend arrow.
- The number may count up from zero when its page comes in. It does not count again when a sync redraws the page.
