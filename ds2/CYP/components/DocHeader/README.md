# DocHeader

The top of every document an app makes: the seal, the project name, the document title, and three facts about the document. The consumer provides the title, and the values for centre or section, period, and the app that made the document.

- Seal 72px on the left. Project name in `label-caps`, `blue`. Title in `heading-2`.
- The facts sit on the right as label and value, value in bold.
- A 3px `blue` rule closes the header.
- The header is the same on every internal template, whatever app makes it.
