# ChapterOpener

A full page on the blue ground that opens a numbered chapter. The consumer provides the chapter number and the title (three lines at most).

- Number in `chapter-number` with a full stop, title in `opener-title` in capitals, both white and centred.
- No photo, no body text, no icon.
- Use it for the numbered chapters of the report only. A sub-section opens with `SectionOpener`.
