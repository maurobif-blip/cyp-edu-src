# Logos

- `cyp-seal.png` - the Cicetekelo Youth Project seal, 600 by 562px, blue on a white ground. No transparent or vector version: on a colour, keep the white plate. For print larger than 50mm, ask the project for the original artwork.
- `cyp-edu.svg`, `cyp-fin.svg`, `cyp-eat.svg` - the app wordmarks. Letters CYP in `blue-sky`, the app name in the chitenge pattern. Smallest height 24px.
- `cyp-edu-icon.svg`, `cyp-fin-icon.svg`, `cyp-eat-icon.svg` - home-screen icons, 512px square on white. The phone rounds the corners.
- `chitenge-strip.svg` - the pattern as a band, for tools that cannot use the CSS class `cyp-chitenge`.
