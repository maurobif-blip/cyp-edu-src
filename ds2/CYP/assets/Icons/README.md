# Icons

Forty icons from Lucide 0.378.0 (ISC licence, text in `licenses/Lucide-ISC.txt`), 24px, stroke 1.75, drawn in `ink` (#14213D).

- In a page, inline the SVG, remove its `stroke` attribute and add class `cyp-icon`: the icon then takes the colour of the text around it, or white inside a `cyp-disc`.
- As `<img>` the files stay `ink`: use them that way on `surface` and `surface-soft` only.
- Add an icon only from the same Lucide version, with the same stroke.
